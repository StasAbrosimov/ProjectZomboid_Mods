# Readme
This is rep for Project Zomboid mods.

CP_StairsAlert_un_tr is mod for  [Project Zomboid](https://store.steampowered.com/app/108600/Project_Zomboid/) game.
This mod ([Translation Fix](https://steamcommunity.com/sharedfiles/filedetails/?id=3723543546)) is the patch that add fixed translation files for original mod [Stairs Alert](https://steamcommunity.com/sharedfiles/filedetails/?id=3044807092) by BitBraven

My own mod [Keychain Manager](https://steamcommunity.com/sharedfiles/filedetails/?id=3735659907) for managing numerous keys.
And new translation fix [DrawOnMap unofficial Translationfix 42.15+](https://steamcommunity.com/sharedfiles/filedetails/?id=3730922136).

Feel free to add pull request for new languages
